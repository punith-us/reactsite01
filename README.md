# React Learning Project

This project is a personal playground for learning and experimenting with React.js. It includes hands-on practice with components, props, state, CSS styling, and integration with assets.

## Features
- Custom Navbar and Hero section
- Responsive layout and background images
- Practice with React functional components
- CSS modules and styling
- Git and GitHub workflow

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/punith-us/reactsite01.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```

## Purpose
This repository is for learning React fundamentals, experimenting with UI, and understanding modern web development workflows.
